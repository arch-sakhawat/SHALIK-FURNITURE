# InstantSKP

**InstantSKP** is a free plugin for **Rhino 8** that allows you to browse the **SketchUp 3D Warehouse directly from Rhino** and import models with materials in just a few clicks.

It’s a **handy, everyday tool** designed to speed up architectural, interior design, and 3D modeling workflows without leaving Rhino.

---

## Features

- Browse the SketchUp 3D Warehouse directly inside Rhino  
- Import models straight into your Rhino document  
- Materials are imported automatically  
- Fast, simple, and practical workflow  
- No login required  
- **No usage limits imposed by the plugin**  
- 100% free

> Note: Access to third-party services such as SketchUp 3D Warehouse may be subject to
> limitations, availability, or terms defined by their respective providers.

---

## Requirements

- **Rhino 8**
- **Windows x64**

---

## Installation

### Rhino 8 (Windows) — Package Manager
InstantSKP can be installed directly from the **Rhino Package Manager**:

1. Open Rhino 8  
2. Run the `PackageManager` command  
3. Search for **InstantSKP** in the panel menu.
4. Install and restart Rhino  

---

## Usage

1. Launch InstantSKP from Rhino  
2. Browse or search the SketchUp 3D Warehouse  
3. Select a model  
4. Import it directly into your scene  

Models are added to the document with their materials automatically assigned.

InstantSKP itself does **not enforce usage limits**. Any restrictions related to access,
downloads, or availability are determined by the SketchUp 3D Warehouse service.
